Architecture

Databricks is the CDC engine; Kafka is the contract

Capture runs inside Databricks: notebooks poll each source, detect what changed, and publish the changes to Kafka. Downstream consumers, including this project's own Delta pipeline, read the topics and never touch the source systems.

Job graph

One Databricks Workflows job, defined in databricks.yml (Asset Bundle) and scheduled every five minutes with max_concurrent_runs: 1, because each watermark assumes a single writer.

capture (for_each: sqlserver_cards, partner_fileshare)
   └─ bronze ─ silver ─┬─ gold
                       └─ reconcile   (fails the run on any mismatch)

Design choices that matter

Deterministic event IDs

event_id = sha256(system | table | key | source position). If capture crashes after producing but before committing the watermark, the replay produces the same IDs and Bronze's MERGE drops them. That gives at-least-once delivery on the wire and exactly-once in Delta.

Watermark last

The order is produce → flush → audit → watermark. If any message is not acknowledged, the run fails and the watermark stays where it was. Data is never skipped; at worst it is sent twice and deduplicated.

Ordering guard in Silver

Silver updates a row only when the incoming source sequence (SQL Server LSN, or file timestamp plus line) is newer than the stored one. Late or replayed changes cannot roll a balance back.

Soft deletes

A delete sets _is_deleted instead of removing the row, so an older insert cannot bring it back. It also keeps evidence: an expired card authorisation still counts as an attempt for the fraud rules.

Config-driven sources

conf/sources.yml lists each source's tables, keys, topic and Silver schema. Adding a table is a config change. A new source type needs one adapter class that implements capture() and source_stats().

Secrets out of the repo

Credentials come from a Databricks secret scope on the platform and from environment variables locally, through the same getter. With a Confluent API key present, the Kafka config switches to SASL_SSL automatically.
