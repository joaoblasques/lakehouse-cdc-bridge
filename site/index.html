The business problem

Today at Banco Atlântico (fictional)

  • Core data sits on four systems: a DB2 mainframe, a SQL Server cards platform, SingleStore for instant payments, and partner files on an Azure File Share.
  • Every team that needs the data queries those systems on its own. Mainframe reads cost MIPS, and nobody owns a single version of the data.
  • Fraud and AML checks run as next-day (T+1) batch reports. A card skimmed at 10:00 is noticed the following morning.
  • When a regulator asks where a number came from, the answer takes days.

What this project builds

  • One capture layer on Databricks, driven by config. Each source gets the CDC technique it can support (log, file manifest, watermark).
  • One event contract on Kafka, so downstream teams subscribe to topics instead of querying the sources.
  • Delta audit trail: every event's Kafka offset and source position, plus a reconciliation job that fails loudly when anything is missing.
  • Fraud alerts on the stream, scored against planted fraud with precision and recall.

Stack

Capture

Python adapters run from Databricks notebooks. SQL Server native CDC; Azure File Share SDK with a Delta manifest.

Transport

Kafka (Confluent): one topic per entity, idempotent producer, a dead-letter topic for bad records.

Storage

Delta Lake: control and audit tables, Bronze (dedup), Silver (MERGE with ordering guard), Gold alerts.

Orchestration

Databricks Workflows via an Asset Bundle: a for-each task over the sources, then Bronze, Silver, Gold and reconciliation.

Processing

Apache Spark Structured Streaming with availableNow triggers, and Spark SQL window functions for the rules.

Quality

pytest (unit, Spark, SQL Server integration), ruff, GitHub Actions CI.

Scope, stated plainly

The MVP covers SQL Server and Azure File Share. DB2 and SingleStore adapters are next (see Decisions): neither has a free cloud tier that supports CDC, so they will be tested locally in Docker. The numbers on this site come from a real local run (Docker SQL Server and Confluent Kafka, local Spark and Delta). The same code runs on Databricks through the Asset Bundle.
