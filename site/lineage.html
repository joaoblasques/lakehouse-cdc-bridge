Traceability

From an alert back to the exact source change

An auditor asks: why was this account flagged, and can you prove the data is what the bank's system recorded? Pick an alert from the last run and follow it back, step by step, to the database transaction or file line it came from.

Why it matters: regulators expect banks to trace every reported number to its source (BCBS 239). Here that is built in: each step keeps the IDs of the step before it (lineage).

The query behind it

The same walk as one SQL query: alert → its payments in Bronze → where each one sat in Kafka (audit trail).

SELECT a.rule, a.account_id, b.op, b.source_position, b.source_commit_ts,
       au.topic, au.kafka_partition, au.kafka_offset, au.payload_hash
FROM   gold_fraud_alerts a
JOIN   bronze_change_events b
       ON b.source_table = 'dbo.card_transactions'
      AND get_json_object(b.key_json, '$.tx_id') IN (SELECT explode(a.evidence_keys))
JOIN   cdc_event_audit au ON au.event_id = b.event_id
WHERE  a.alert_id = :alert_id
ORDER  BY b.source_sequence;
