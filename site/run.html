Run it

Reproduce the results

On your own machine in about 15 minutes, with no cloud account. You need Docker, Java 17 or newer (for Spark) and uv (a Python package manager).

On your machine

  1. Clone and install 
    git clone https://github.com/joaoblasques/lakehouse-cdc-bridge && cd lakehouse-cdc-bridge
uv sync --all-extras
  2. Start the two source-side services: SQL Server (with its capture job enabled) and Kafka (in KRaft mode) 
    docker compose up -d --wait
  3. Run the automated tests (pytest): first the fast ones, then one that uses the real SQL Server 
    uv run pytest
uv run pytest -m integration
  4. Run the whole pipeline: it loads starting data, simulates 6 hours of bank activity, processes each hour end to end, and writes the results to site/data/run_metrics.json 
    uv run python scripts/run_local.py --fresh
  5. Open this website locally to see your own numbers 
    python -m http.server -d site 8000   # http://localhost:8000

On Databricks and Confluent Cloud

  1. Store the passwords in a secret scope. The key names match conf/sources.yml 
    databricks secrets create-scope banking-cdc
databricks secrets put-secret banking-cdc mssql-cards-host      # Azure SQL server
databricks secrets put-secret banking-cdc mssql-cards-port
databricks secrets put-secret banking-cdc mssql-cards-user
databricks secrets put-secret banking-cdc mssql-cards-password
databricks secrets put-secret banking-cdc fileshare-partner-connection-string
databricks secrets put-secret banking-cdc kafka-bootstrap        # Confluent Cloud
databricks secrets put-secret banking-cdc kafka-api-key
databricks secrets put-secret banking-cdc kafka-api-secret
  2. Switch on CDC in the Azure SQL database by running sql/sqlserver/001_cards_schema.sql. Azure SQL runs its own capture scheduler, so there is no Agent to set up.
  3. Deploy and run with the Asset Bundle: one command builds the code and creates the job 
    databricks bundle deploy -t dev
databricks bundle run banking_cdc
The job is deployed with its schedule paused. Start it on purpose: a five-minute schedule on a trial account uses up its free credit faster than you'd expect.

Where things are in the code

conf/sources.yml            sources, tables, keys, topics, Silver schemas
src/banking_cdc/
  envelope.py               the change event (deterministic event_id)
  generator.py              synthetic Banco Atlântico + planted fraud
  sources/sqlserver.py      log-based CDC (LSN watermark, gap detection)
  sources/fileshare.py      file-arrival CDC (etag + sha256 manifest, DLQ)
  pipeline/                 capture, Bronze/Silver, reconciliation, Gold rules
  evaluate.py               precision / recall against ground truth
notebooks/                  thin Databricks tasks over the package
databricks.yml              Asset Bundle: Workflows job with for-each capture
scripts/run_local.py        end-to-end run → site/data/run_metrics.json
schemas/                    event JSON Schema
site/                       this website (static HTML/CSS/JS)
